# UsabilityHub Website Clone

A responsive frontend recreation of the UsabilityHub landing page, built using HTML5 and CSS3. This project focuses on recreating a modern SaaS landing page with structured sections, responsive layouts, and interactive navigation.

## 📌 About The Project

This project is a frontend recreation inspired by the UsabilityHub website.

The goal was to practice building a complete landing page using fundamental frontend technologies while exploring modern website layouts, responsive design, and reusable styling patterns.

## ✨ Features

- **Announcement Banner** – Promotional announcement section.
- **Navigation Bar** – Navigation links with a mobile menu toggle.
- **Hero Section** – Introduction with a call-to-action.
- **Company Logos** – Brand showcase section.
- **Feature Cards** – Grid-based presentation of product features.
- **Audience Sections** – Dedicated sections for designers, marketers, and product managers.
- **Call-to-Action** – Dedicated conversion-focused section.
- **Footer** – Multi-column navigation layout.
- **Responsive Layout** – Adaptable styling for different screen sizes.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/Shifakhan1929/usabilityhub-website-clone.git
```

**2. Navigate to the project directory**

```bash
cd usabilityhub-website-clone
```

**3. Open the project**

Open `index.html` in your browser or use the Live Server extension in VS Code.
